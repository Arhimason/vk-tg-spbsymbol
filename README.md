# vk-tg-bridge

Личные сообщения ВКонтакте приходят в Telegram отдельными супергруппами: один диалог VK — один чат. Ответ из этого чата уходит обратно тому же собеседнику.

Нужны пользовательский токен VK с доступом к личным сообщениям и личная сессия Telegram. Токена сообщества или бота для ящика VK недостаточно: бот только публикует входящие в уже созданные чаты. Группы создаёт пользовательская сессия Telethon. Прокси нет, Telethon ходит в Telegram напрямую.

## Как это устроено

Новый `peer_id` получает чат в момент первого входящего сообщения либо сразу по команде `/a`, не дожидаясь переписки. Название собирается из имени VK: диалог и сообщество — `[VK] Имя`, беседа — `[VK] [Группа] Имя`. Если у страницы есть своё фото, на него ставится синий значок VK.

В беседе каждое сообщение в Telegram подписано отправителем (`Имя:` и текст). В личном диалоге и в диалоге с сообществом такой строки нет.

Сообщения, набранные в самом приложении VK, в Telegram не копируются. Удаление и правки чужих сообщений в Telegram не стирают оригинал у собеседника: стирается только то, что ушло в VK как ваше.

Служебный чат «VK-мост» создаётся один раз и не связан ни с каким диалогом VK. В нём закреплено состояние моста, туда же приходят ошибки.

## Запуск

Зависимости ставятся через [uv](https://docs.astral.sh/uv/). Python 3.13 или новее.

```bash
uv sync
cp .env.example .env
uv run vk-tg-bridge login
uv run vk-tg-bridge
```

В `.env` нужны токен VK, `api_id` и `api_hash` с [my.telegram.org](https://my.telegram.org), токен бота и путь к сессии. Сессия мессенджера VK продлевается сама из `data/vk-session.json` (клиент `51453752`) примерно за пять минут до истечения access token.

Рядом можно держать наблюдатель. Он не открывает сессию Telegram и раз в минуту смотрит файл пульса. Если мост молчит дольше десяти минут, бот один раз пишет об этом в служебный чат.

```bash
uv run vk-tg-bridge watch
```

Если компьютер выключен, наблюдатель останавливается вместе с ним.

## Команды

Команды читает пользовательская сессия, потому что бот в группах не видит обычные сообщения.

| Команда | Где работает | Что делает |
| --- | --- | --- |
| `/a` и одна или несколько ссылок через пробел | личка бота, «VK-мост» или уже открытый чат моста | сразу создаёт чат по странице VK |
| `/status` или `статус` | только «VK-мост», одним словом | обновляет закреп и присылает то же текст сообщением |

Подходят адреса `vk.com` и `vk.ru`, в том числе мобильные, а также `id`, короткое имя, `club`, `public` и `event`. Команда `/a` в диалог VK не пересылается. Пример: `/a https://vk.com/id1 https://vk.com/durov`.

В `src/vk_tg_bridge/constants.py` есть переключатель `RELAY_CHAT_MEMBERS`. Когда он включён, сообщение любого участника чата, кроме бота, уходит в VK как ваше. Сообщения бота обратно не отправляются.

## Покрытие сообщений

В одном сообщении VK переносится до десяти вложений. Остальные заменяются строкой `[ещё вложений: N]`. Пересланные сообщения раскрываются на один уровень. Ответ цепляется к исходному сообщению, если пара уже есть в базе. Старое сообщение без пары уходит обычным текстом, без цитаты.

### ВКонтакте → Telegram

| Тип | Как приходит |
| --- | --- |
| Текст | текст |
| Фото, граффити | фото |
| Стикер | картинка, анимированный — файлом `webm` |
| Голосовое | голосовое (`ogg`) или аудио (`mp3`) |
| Видео, клип | видео, если есть прямой `mp4`; иначе название и ссылка на плеер |
| Видеосообщение | кружок |
| Аудио | аудиофайл либо строка «исполнитель — название» |
| Документ | фото, GIF, видео, аудио или файл по расширению |
| Ссылка, запись, комментарий, опрос, товар | текст |
| Подарок, звонок, история и прочие типы без файла | короткая пометка в скобках |
| Пересланное | текст «Переслано: …» и вложения, один уровень |

### Telegram → ВКонтакте

| Тип | Как приходит |
| --- | --- |
| Текст | текст |
| Фото и картинка-документ | фото |
| Голосовое | голосовое |
| Видео | обычное видео |
| Кружок | круглое видеосообщение VK; если VK его не принял — обычное видео |
| GIF | обычное видео |
| Стикер | файл `webp`, `webm` или `tgs`, не стикер VK |
| Аудио | файл |
| Документ | файл |
| Пересланное | текст «Переслано от …» |
| Контакт, место, геопозиция, опрос, кость | текст |

## Правки, удаления, ответы, отметки

Своя правка в Telegram меняет то же сообщение в VK. Своё удаление удаляет его в VK для всех, насколько это позволяет VK: `delete_for_all` обычно действует около суток.

Чужая правка в VK не затирает копию в Telegram. Под старым текстом появляется блок `ревизия · 15 окт 20:41` и новый текст. Чужое удаление тоже остаётся в чате: снизу дописывается `удалено · 15 окт 20:45`. Повтор той же версии или повторное удаление строку не дублируют.

После успешной отправки в VK на сообщение в Telegram ставится реакция 👌. Когда собеседник дочитал исходящие до этого места, 👌 сменяется на 👀. Глазки ставятся в фоне и не задерживают новые сообщения: если человек разом прочитал много сообщений и тут же написал своё, текст приходит сразу, а реакции догоняют следом. В беседе событие чтения не называет, кто именно прочитал. Сообщения, набранные только в VK, в этой таблице нет, поэтому реакции на них не будет.

Пока собеседник печатает, бот показывает «печатает» в уже открытом чате. Ради набора новый чат не создаётся.

Для личного диалога описание чата — это статус: «онлайн», «был 15 окт 21:10» или «не в сети», если VK время скрыл. Описание обновляется по событиям long poll и раз в минуту запросом `users.get`. У бесед и сообществ статус не личный, описание остаётся «Диалог ВКонтакте».

## Ошибки и пульс

Закреп в «VK-мосте» обновляется раз в три минуты: мост жив, время, состояние long poll и срок токена VK. Явная поломка приходит туда отдельным сообщением: не создался чат, не дошло сообщение, не применились правка или удаление, оборвался long poll, не обновился токен. Тот же сбой повторяется не чаще раза в 15 минут. Набор текста, реакции и аватарки в этот чат не пишутся.

## Ограничения

- Telegram даёт создать примерно 50 новых супергрупп в сутки. При упоре в лимит мост пишет подробности в «VK-мост». Сообщение, из-за которого чат не создался, в Telegram не попадает и само не повторяется.
- Длинная пауза Telegram (`FloodWait`) на переименование или реакции только пишется в журнал. На создание чата и на доставку сообщения такая пауза видна в служебном чате.
- Фото в Telegram — до 10 МБ. Остальные файлы бота — до 50 МБ. В VK фото и видео — до 50 МБ, голосовое — до 10 МБ. Более крупный файл заменяется пометкой.
- Текст длиннее 4096 символов обрезается. В истории правок остаётся хвост.
- Стикеры Telegram не становятся стикерами VK. Стикеры VK не становятся стикерами Telegram.
- Видео VK без прямой ссылки на `mp4` приходит названием и ссылкой на плеер.
- Счета, платные медиа, игры и живая геопозиция дальше текстовой пометки не идут.
- Запись голосового в VK (событие «записывает аудио») в Telegram не показывается. Пока человек печатает текст, индикатор есть.
- В беседе Telegram не умеет написать, кто именно печатает или кто прочитал.
- Если человек скрыл время захода, в описании будет «не в сети» без даты.
- Сообщения, отправленные из приложения VK, в Telegram не появляются, поэтому на них нельзя ответить, поставить реакцию и протянуть правку.
- Удаление в VK для всех может не сработать для старого сообщения.
- Наблюдатель локальный: выключенный компьютер он не заметит снаружи.
